# Media Toolkit

Media Toolkit est une application Windows pour compresser, convertir et modifier tes vidéos, tes images et tes fichiers audio.

- **Compresser** · Choisis un format de sortie, une résolution et, si tu veux, une taille cible en Mo. Tu peux tester un extrait et estimer le temps et le poids avant de lancer.
- **Convertir et ajuster** · Change le format, la taille ou les couleurs de tes fichiers et compare l’avant/après.
- **Montage rapide** · Coupe ou fusionne des vidéos, crée un GIF, capture une image ou extrais le son.

## Démarrage

1. Installe Python et [FFmpeg](https://ffmpeg.org/download.html).
2. Télécharge `MediaToolkit.pyw` depuis les [versions GitHub](https://github.com/MATTRAX64/Medias_Toolkits/releases).
3. Double-clique sur le fichier. Si FFmpeg est introuvable, indique le chemin de `ffmpeg.exe` dans **Paramètres**.

L’interface et le code sont dans le même fichier `.pyw`. Tes fichiers d’origine sont conservés lors des exports.
